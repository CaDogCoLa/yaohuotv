# 妖火影视 — 产品简介与更新说明

> 一款兼容 **TVBox 订阅源** 的 Windows PC 桌面影音客户端（基于 Electron 构建）。
> 不内置任何影视/直播源，不提供、不存储、不传播任何版权内容；所有片源均来自用户自行导入的第三方公开订阅。

------

## 一、产品简介

**妖火影视** 是一个轻量的 PC 端影音浏览器。它的核心价值只有一件事：**把你已有的 TVBox 订阅源，在电脑上用起来**——点播、直播、搜索、看历史，一个窗口搞定。

与手机端 TVBox 不同，妖火影视面向桌面场景做了几件关键的事：

- **导入兼容性强**：不仅支持标准 JSON 配置，还兼容 XML 单接口、MacCMS `api.php` 单接口、整段 base64 / base64url、gzip+base64、JSONP、脏 JSON 等多种形态，导入失败会给出清晰的错误指引。
- **点播体验现代化**：首屏是豆瓣热榜影视墙，点击任意卡片即按片名搜索；搜索结果支持多源横向标签切换；海报图懒加载 + 并发限速，长列表也不卡。
- **观看历史跨源续播**：切换源后点历史记录，若当前源没有该站点，会自动切回它所属的源再播放，不会「点不开」。
- **播放更稳**：播放卡顿时后台检索同剧同集的更快源并按测速无缝切换；JS 爬虫子集（单站 `.js` / 全局 `.js` 爬虫）可正常浏览与播放，且全程不阻塞界面。
- **干净、合规**：无内置源、无推荐模块；窗口底部常驻免责声明小字。

## 二、功能特性

| 模块     | 能力                                                         |
| -------- | ------------------------------------------------------------ |
| 订阅管理 | 导入（URL / 文件 / 文本）、导出、缓存清理、数据目录查看、源体检 |
| 导入兼容 | JSON、XML 单接口、MacCMS `api.php`、base64 / base64url、gzip+base64、JSONP、脏 JSON、302、HTML/500 友好报错 |
| 点播     | 豆瓣热榜影视墙（7 个实测可用榜单）、分类/列表/详情/搜索、按片名搜索卡片 |
| 搜索     | 多源结果聚合 + 顶部横向标签按源筛选；命中即播                |
| 观看历史 | 跨源自动切换所属源续播；海报懒加载                           |
| 播放器   | HLS（hls.js）、卡顿自动切换更快源、进度记忆、全屏、自定义标题栏 |
| 直播     | 支持 M3U / TXT 等多种写法                                    |
| 爬虫     | JS 爬虫子集（catvod / drpy 风格）在 worker 线程执行，不卡 UI；`.jar` 爬虫 PC 端明确标注不支持 |
| 域名     | 中文 / IDN 域名订阅源自动转 punycode 归一化                  |
| 打包     | 便携版（双击即跑，数据自包含）+ NSIS 安装版（可改目录、建快捷方式） |
| 在线更新 | 设置内「检查更新」：拉取开源仓库（GitHub 等）托管的 update.json，比对版本号，**非强制**——发现新版本仅提示并提供下载链接，绝不自动安装 |
